How My Snake Game Processes Player Movement

This web page explains a portion of a Python-based Snake game that handles player input, snake movement, and collision detection. The program runs continuously inside a game loop as long as the variable snakeAlive remains true.

The program listens for keyboard input using the getkey function and stores the result in the variable key. Arrow key input changes the value of the direction variable, while pressing q immediately ends the game.

Code Fragment

The following segment of code is from my final project in my Python class I made in the Fall of 2025. It shows how user input controls the snake and how the game responds to collisions and fruit collection. 


    while snakeAlive:
        try:
            key = stdscr.getkey()
        except:
            key = None

        if key == "KEY_LEFT" and direction != "RIGHT":
            direction = "LEFT"
        elif key == "KEY_RIGHT" and direction != "LEFT":
            direction = "RIGHT"
        elif key == "KEY_UP" and direction != "DOWN":
            direction = "UP"
        elif key == "KEY_DOWN" and direction != "UP":
            direction = "DOWN"
        elif key == "q":
            snakeAlive = False
            break

Once the direction is set, the program updates the snake’s head position by modifying the x and y coordinates. For example, moving left subtracts from x, while moving down adds to y. If the snake reaches a border, the output of the program is a game over condition.

When the snake’s head reaches the fruit coordinates stored in fruitX and fruitY, the program increases both snakeLength and score. This causes the snake to grow and shows the player how far they have progressed!

One useful acronym related to this program is FPS, which describes how frequently the game loop updates the screen and processes input.
